\begin{frame}{¿Por qué estructuras de datos?}
\begin{block}{Eficiencia y Escalabilidad}
No basta con que el código funcione; debe ser óptimo cuando los datos crecen (Big Data).
\end{block}
\begin{itemize}
\item \textbf{Búsqueda:} Árboles para buscar entre millones de datos al instante.
\item \textbf{Historial:} Pilas (Stacks) para el Deshacer (Ctrl+Z).
\item \textbf{Planificación:} Colas (Queues) para procesos del SO.
\item \textbf{Conectividad:} Grafos para rutas GPS o redes sociales.
\end{itemize}
\end{frame}
